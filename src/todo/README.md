#  My Travel Log App

Capture memories, rate locations, and save your favorite spots—even when you are offline!

##  Key Features

* **Offline First:** Continue adding and editing trips without internet. Data syncs automatically when you go back online.
* **Photo Memories:** Take photos using the camera or upload from your gallery.
* **Interactive Maps:** Pin your travel locations using Leaflet maps.
* **Smart Filtering:** Search by name, filter by star rating, or find places you want to visit again.
* **Tropical Theme:** A beautiful, animated UI designed to get you in the mood for travel.
